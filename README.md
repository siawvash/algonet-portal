# Algonet Integrated Portal (پورتال یکپارچه الگونت)

نسخه ۳.۰ پورتال جامع خدمات سازمانی، پلتفرم‌های ابری و سامانه‌های یکپارچه الگونت.

## 🚀 ویژگی‌ها
- **طراحی مدرن و ریسپانسیو**: کاملاً منطبق بر سیستم دیزاین الگونت، بهینه‌سازی‌شده برای دسکتاپ، تبلت و موبایل.
- **ناوبری هوشمند**: سایدبار مدرن، نوار ناوبری شناور در موبایل با ترنزیشن‌های مورف روان و فیزیک فنری.
- **سرویس‌های سازمانی و ابری**: دسترسی سریع به پلتفرم‌های AI، دریاچه داده، IDP و سرویس‌های عمومی.
- **تم تاریک و روشن**: پشتیبانی کامل از حالت دارک و لایت بر اساس توکن‌های رنگی رسمی الگونت.
- **فونت بومی و اعداد فارسی**: پشتیبانی آفلاین و درون‌سازمانی با تایپوگرافی وزیرمتن.

## 🛠️ فناوری‌ها
- React 18
- TypeScript
- Tailwind CSS
- Vite
- Lucide React

## 💻 راه‌اندازی و توسعه
```bash
# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه
npm run dev

# ساخت نسخه پروداکشن
npm run build
```
